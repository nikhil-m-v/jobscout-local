# 0031 — Core acceptance and deferred release gates

Date: 2026-10-11. Status: adopted user-approved delivery reset.

Milestone 17D bundled search quality, installed Windows behavior, full accessibility and resource acceptance. Repeated narrow acceptance slices delayed local saving and tracking. Redefine 17D as **core development acceptance**, with the finite checklist in [the acceptance matrix](../milestone17-acceptance.md#core-development-exit-checklist). Reuse applicable evidence and run current checks; do not add a live trial, extraction feature or full installation audit merely to close this milestone.

This decision supersedes the saving/tracking prerequisites and acceptance sequencing in decisions [0027](0027-ten-to-twenty-shortlist.md), [0028](0028-release-based-delivery.md), [0029](0029-bounded-ats-title-evidence.md) and [0030](0030-work-requirement-review-notes.md), and earlier roadmap/checkpoint next actions. Their measurements, implementation boundaries and evidence limitations remain valid. It does not relax [the privacy contract](../privacy.md).

## Finite closure and blockers

Require reviewed generic queries with fixed request bounds, cancellation/partial recovery; safe rendering with source-linked evidence, reversible filters and retained alternatives; basic keyboard/compact/theme behavior; bounded installed first-use/profile restart/normal-close evidence; and passing current engine/frontend suites, shortlist evaluation, typecheck and build. No unresolved demonstrated privacy, data-loss or critical lifecycle defect may be waived to close 17D. Such a defect blocks affected functionality until fixed.

Reuse recorded browser/native development checks and separate-identity installed observations, explicitly retaining their fixture, identity and binary limitations. The later work-requirement disclosure has browser and regression evidence, not fresh native/installed evidence. Passing automated checks does not supply missing interactive evidence. Closure is **core acceptance complete; broader quality and release acceptance deferred**; it does not mean v1.0 is ready.
