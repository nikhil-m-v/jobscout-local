## User impact and implementation

Editable-field borders used the same low-contrast token as decorative dividers.
Against field fill, the original colors measured 1.341:1 in Light and 1.394:1 in
Dark. A dedicated `--control-line` now gives 3.664:1 and 3.520:1 respectively,
exceeding 3:1 against canvas, surface and card. This applies to resume/query/notes
editors, public criteria and tracking selects, the masked key field and local
folder input. Forced colors retains a `CanvasText` boundary. Text, backgrounds,
panel dividers, data flow and dependency versions are unchanged. The fix is CSS
only; forced-color OS rendering itself was not exercised.

Added an offline sRGB contrast audit with numerical reference and failure
regressions. All 70 checks pass: 58 normal-text semantic pairs at 4.5:1 and twelve
field-boundary/focus comparisons at 3:1. The weakest checked normal-text pair is
Light warning text on selected fill, 4.668:1. Glass compositing, every native widget
and every rendered pixel are outside this mathematical audit.

Added a bounded current-user display helper. It captures exact original app-color,
transparency and client-animation preferences, refuses baseline overwrite and
redirected evidence, limits changes to the separate production-engine installation,
validates restore inputs and verifies restoration even after uninstall. It changes
no security or privacy settings. The client-animation API follows Microsoft's
[SystemParametersInfo contract](https://learn.microsoft.com/windows/win32/api/winuser/nf-winuser-systemparametersinfow).
The original values were restored and read back twice after the final UI checks,
including after uninstall.

Default notice recollection correctly stopped on 24 changed/missing and 24
unexpected/changed native identities from host-input drift. The new explicit
`--retained-notices` frontend-only build path verifies the retained package,
exact frozen engine/notice inventory and current-versus-retained npm dependencies
and Cargo packages/resolve metadata before reuse. Changed versions, licenses,
features or missing evidence fail closed. This preserves existing native evidence
without granting new provenance, license clearance or recipient source delivery.
