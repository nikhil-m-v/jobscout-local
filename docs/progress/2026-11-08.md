## Failure, change and user impact

After keyboard Continue from Your workspace to Online search, actual Narrator
speech recap said only the main landmark and that loading had finished. It did
not announce the new step's title. The application focused the generic main
landmark on every setup step change, leaving screen-reader users without the
new step's name.

Setup entry and step changes now focus the current `setup-step-title` heading.
Each step's level-2 heading accepts programmatic focus with `tabIndex={-1}` and
stays outside the normal Tab sequence. Other workspace pages keep their existing
main-landmark target. A scoped focus-visible rule uses the existing accent token
and outline spacing, replacing the faint browser-default heading outline.

This changes UI orientation only. The guide's default, remembered step, optional
key setup, review/send permissions, storage/recovery behavior and engine remain
unchanged. No dependency, schema, new setup requirement or privacy change.
GitHub connector searches for all repository PRs and open PRs returned empty
results before choosing the local fix.
