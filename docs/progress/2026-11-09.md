## Milestone 24B — offline preflight foundation

24A with one bounded engine slice: `embedding_preflight.py`, an offline exact-byte
verifier and single-volume incremental space planner. The existing catalog and
setup-later experience are unchanged.

Artifact identity requires full SHA-256 and exact nonzero size; short registry
IDs and matching filenames/tags cannot substitute. Verification reads bounded
chunks, rejects over/undersize and corrupted data, supports cancellation and
never converts read errors into success. Budgeting includes final copies,
temporary staging, runtime, additional recovery copies and reserve. Explicitly
verified blobs reused in place remove only their transfer/final-copy costs.
Unknown space stays unknown; invalid counts, integer overflow, duplicate or
conflicting pins and unrelated reuse fail closed. These checks do not establish
license clearance, recipe compatibility, runtime capability or download consent.

The implementation performs no network, filesystem discovery, file mutation,
runtime inspection, inference or career-data access. There is no production
manifest, enabled pin, API/UI integration, persisted state, schema migration,
dependency or permission change. Inputs are internal typed values, not an
untrusted manifest parser. Future callers must select stable regular files
explicitly, hash on a worker, reverify before use and inspect the separate
fixed-drive destination. Existing shared models/runtime must remain untouched.
