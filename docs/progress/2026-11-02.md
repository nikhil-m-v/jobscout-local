## Implementation and boundaries

- Extended the existing installed builder with explicit `--synthetic-search`.
  The release shell uses the separate `app.jobscout.installedacceptance` identity
  and an acceptance-only frozen entry point. Production `create_app`, search
  adapter, HTTP server and owner watcher run with `httpx.MockTransport`, an
  in-memory synthetic key and an offline model stub. There is no live mode,
  endpoint override, real vault read or hosted/local inference fallback.
- The first fixed-scope response returns one synthetic candidate. The second
  transport waits under the unchanged adapter timeout until shutdown cancels it.
  Unexpected destination/authentication/body/dispatch fails closed. Only exact
  generic Software engineer / India / Remote / any-seniority / no-skill criteria
  are accepted by this fixture. No result site or embedded resource is fetched.
- Added a finite evidence runner: seed full synthetic records, bind an active
  journal to the captured installed engine, mark that it is still active
  immediately before closure, require shutdown before cancellation and no third
  dispatch, verify explicit listener refusal and owned-process exit, compare full
  saved API responses and SQLite integrity, and record zero automatic searches
  after restart. Per-launch atomic journals contain only fixed events/counters,
  PID and loopback port. Reports/fixtures remain ignored.
- Fixed a demonstrated snapshot ownership bug: an old compiler helper's
  historical parent PID had been reused for the desktop. Snapshots now retain
  handles and reject children older than their parent; legacy snapshots cannot
  claim members older than their desktop. The guarded forced-desktop action also
  retains its target handle before identity checks. No unrelated process was
  terminated to obtain a cleanup pass.

The wrapper initially rejected normal self-pointing storage routing files, then
the environment's packaged Windows AppData projection. Both test-only guards
were corrected and regression-tested. The initial installations were guardedly
uninstalled; their separate reports are retained. The evidence runner now prefers
the existing PowerShell 7 host without changing execution policy and allows four
seconds for Windows to return explicit connection refusal (observed refusal took
about two seconds). An earlier normal run lacked the final immediate-close mark
and did not establish cancellation ordering; its reports are archived separately
and excluded from the final two-case acceptance. No timing limit or shutdown
latency claim is inferred from an after-close verifier.
